# Boost Chahyn ⚡

Appli **séparée** de Maison Chahyn : l'optimiseur du Galaxy S26 Ultra.

**Téléchargement direct :** https://github.com/chahynelabbouni-cyber/MAISON-CHAHYN/releases/download/boost-latest/BoostChahyn.apk

## Ce qu'elle fait
- **Accueil personnalisé** : au premier lancement elle te demande prénom, nom et surnom, puis te salue (« Bonjour … 👋 »).
- **⚡ TOUT OPTIMISER** : un seul bouton → RAM libérée + caches cachés + fichiers temporaires, journaux, corbeilles cachées, dossiers vides, .apk, statuts WhatsApp supprimés.
- **🤖 Agent** : tu écris ce que tu veux en français (« mode jeu et libère la RAM », « supprime les doublons », « luminosité 40 », « ouvre Snapchat »). ~200 tâches fixes + 3 par appli installée (ouvrir, vider le cache, désinstaller) → plusieurs centaines au total. Fonctionne hors-ligne.
- **🎛️ 19 modes** : Jeu, Bête de course, Travail, Réunion, Études, Lecture, Film, Musique, Photo, Sport, Voiture, Soirée, Voyage, Économie, Batterie de survie, Nuit, Sommeil, Silencieux, Revenir à la normale.
- **💾 Stockage** : analyse complète (doublons, captures d'écran, médias WhatsApp/Telegram, gros fichiers, vieux téléchargements, vieilles vidéos…), explorateur de tout le stockage trié par taille, applis inutilisées.

## Limites d'Android
Sans root, aucune appli ne peut lire `Android/data` ni vider le cache interne des autres applis : Boost ouvre l'Entretien Samsung pour ça.
Le 120 Hz forcé et les animations demandent une commande ADB lancée une fois depuis un PC.
